# Third-Party Software

NaqshCAD vendors the following third-party code and assets locally (no runtime CDN calls).

| Component | Version | License | Source |
|---|---|---|---|
| Fabric.js | 5.5.2 | MIT | https://github.com/fabricjs/fabric.js |
| dxf-parser | 1.1.2 | MIT | https://github.com/bjnortier/dxf |
| Clipper.js (JS Clipper) | 6.4.2 | Boost Software License 1.0 | https://github.com/junmer/clipper-lib |
| Inter | — | SIL Open Font License 1.1 | https://github.com/rsms/inter |
| Vazirmatn | — | SIL Open Font License 1.1 | https://github.com/rastikerdar/vazirmatn |
| Tabler Icons (toolbar icons, some furniture) | — | MIT | https://github.com/tabler/tabler-icons |
| openPlan3D furniture renderers | — | MIT | https://github.com/laanlabs/openPlan3D |

Most furniture/fixture icons under `assets/furniture/` (the `.png` files) are pre-rendered from openPlan3D's top-down architectural icon renderers (MIT). The remaining `.svg` furniture icons (piano, computer, printer, outdoor items, etc.) are derived from Tabler Icons (MIT).

Full license texts are available at the source repositories above.
